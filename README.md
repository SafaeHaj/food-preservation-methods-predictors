# Food Industry Data Extraction and Analysis Project

**Collaborators:** Safae Hajjout, Zyad Fri
**Supervisors:** Pr. Loubna Benabbou, Pr. Salwa Karboune

**Institutions:** McGill University, Université du Québec à Rimouski (UQAR), UM6P College of Computing

## Overview

This project focuses on the collection, organization, and analysis of food industry data from scientific and technical sources.

The project is divided into two main phases:

### Phase 1: Data Extraction and Generation

* Develop data extraction pipelines using web scraping and automated information retrieval techniques.
* Structure and standardize collected data for downstream analysis.
* Explore methods for generating and enriching datasets from extracted information.

### Phase 2: Prediction and Classification

* Apply machine learning techniques to analyze the collected data.
* Build predictive models to identify patterns and trends.
* Classify food ingredients, treatments, and outcomes based on available information.

## Potential Impact on the Food Industry

The methods developed in this project can help the food industry by:

* Accelerating the extraction of information from scientific literature and technical reports.
* Supporting evidence-based decision-making for ingredient selection and food processing methods.
* Identifying relationships between ingredients, treatments, and food quality indicators.
* Facilitating the discovery of effective preservation and food safety strategies.
* Reducing the time required for literature reviews and knowledge gathering.

## Future Directions

* Expansion of data sources and extraction capabilities.
* Development of more advanced predictive models.
* Integration of explainable AI techniques to improve model interpretability.
* Creation of decision-support tools for researchers and industry professionals.
