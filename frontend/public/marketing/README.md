Notes
- Use photographs you have the right to publish. McGill/Macdonald Campus images
  usually require permission from McGill Communications — do not scrape them.
- Export as progressive JPEG, sRGB, quality ~78. Keep each file under ~400 KB.
- These are decorative: every one is rendered with an empty `alt` and is not
  required for the page to make sense.
